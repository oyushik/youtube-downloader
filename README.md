# YouTube 다운로드 — Windows 데스크톱 앱

`dist/YouTubeDownloader.exe`를 더블 클릭하면 실행됩니다. **배포할 때 이 EXE 하나만 복사하면 됩니다.**
사용자 PC에 Python, Node.js, Deno, FFmpeg, Docker를 별도로 설치할 필요가 없습니다.

대상: Windows 10/11, x64. 인터넷 연결과 다운로드할 파일을 저장할 공간이 필요합니다.
실행할 때 내장 도구를 임시 폴더에 풀기 때문에 창이 표시되기까지 잠시 걸릴 수 있습니다.

## 사용 순서

1. **링크 입력**: 개별 영상 또는 재생목록 전체를 선택하고 YouTube 링크를 붙여 넣습니다.
2. **목록 확인**: 영상 제목, 순서, 길이를 확인합니다.
3. **저장 설정**: 다운로드 폴더를 선택합니다. 순서 번호 추가와 영상·음성 별도 저장을 선택할 수 있습니다.
4. **다운로드**: 진행률과 영상별 성공·실패를 확인합니다.

어느 단계에서든 하단의 **다운로드 내역**을 누르면 별도 화면에서 이전 다운로드를 확인할 수 있습니다.
날짜, 영상·재생목록 제목, 전체 결과와 성공 개수를 최신순으로 표시하며, 내역을 선택하면
영상별 결과, 원본 링크, 저장 파일 경로와 실패 이유를 볼 수 있습니다. 다운로드 중에도 내역을 열 수 있고,
**새로고침**으로 최신 상태를 확인할 수 있습니다.

내역은 `%LOCALAPPDATA%\YouTubeDownloader\history.sqlite3`에 저장되어 앱을 다시 실행하거나
EXE를 교체해도 유지됩니다. 다른 PC로 EXE만 복사하면 그 PC에서는 별도의 내역이 생성됩니다.
이 버전에서 시작한 다운로드부터 기록하며, 이전 버전으로 받은 파일은 자동으로 내역에 추가되지 않습니다.
중지·실패한 작업도 기록하고, **미완료**는 앱이 강제로 종료되는 등 종료 결과가 확인되지 않은 작업입니다.

## 저장 동작

- 영상과 음성의 최상위 포맷을 우선 선택하고 MKV로 병합합니다.
- 개별 영상은 선택한 폴더에, 재생목록은 선택한 폴더 아래의 재생목록 제목 폴더에 저장합니다.
- 한국어 메타데이터를 우선 요청하고 Windows 파일명에 사용할 수 없는 문자를 정리합니다.
- 같은 이름의 기존 파일은 보존하며 영상 ID와 추가 번호로 새 이름을 만듭니다.
- 별도 저장을 선택하면 `video only`에는 무음 영상을 원래 포맷으로, `audio only`에는 16비트 PCM WAV를 저장합니다.
- 결합 포맷만 제공되는 영상은 별도 파일이 생략될 수 있으며 상세 로그에 표시합니다.
- 일시적인 오류는 재생목록을 한 번 처리한 뒤 20~30초 대기하고 한 차례 더 시도합니다.
- **중지** 또는 창 닫기는 현재 작업의 종료를 요청합니다. 진행 중인 네트워크 요청이나 FFmpeg 병합이 끝날 때까지 잠시 걸릴 수 있습니다. 완료된 파일은 보존하고 미완성 임시 파일은 정리합니다.
- 재실행 시 이전 다운로드를 자동으로 건너뛰거나 중간부터 이어받지는 않습니다.

## 실행 구조

앱에 Python/Tk, yt-dlp, EJS, Node.js, FFmpeg/FFprobe, bgutil 서버·플러그인과 Windows용 네이티브 의존성을 포함합니다.
목록 조회와 다운로드는 작업 스레드에서 실행되고 UI에는 큐를 통해 진행 상황을 전달합니다.

작업마다 앱 전용 PO Token 서버를 `127.0.0.1`의 임시 포트로 실행합니다. HTTP 응답을 확인한 뒤 사용하며,
작업 종료 시 서버를 함께 종료합니다. 앱이 강제로 종료되어 부모 프로세스의 파이프가 닫힐 때도 서버가 종료됩니다.
기존 Docker 컨테이너나 시스템 PATH에 있는 프로그램을 사용하지 않습니다.

## 소스에서 실행·빌드

아래 준비는 **개발자 PC에서만** 필요합니다. 빌드에는 Windows x64와 Python 3.14가 필요하며,
`build.ps1`이 프로젝트 안의 `.venv`에 패키지를 설치하고 공식 배포 파일을 받아 서버를 빌드합니다.
시스템 전역 Python 패키지나 Node 설정을 변경하지 않습니다.

```powershell
.\build.ps1 -Python "C:\path\to\python.exe"
```

실행 도구는 버전과 SHA-256을 고정했습니다. 재빌드에 필요한 다운로드·npm 캐시는 `.build-cache`에 저장됩니다.
이미 준비된 실행 도구를 재사용하려면 `-SkipPrepare`를 지정할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe youtube-download.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

빌드 결과: `dist/YouTubeDownloader.exe`

## 구성 파일

| 파일 | 역할 |
| --- | --- |
| `youtube-download.py` | GUI 실행 진입점 |
| `desktop.py` | 한국어 단계별 UI, 작업 스레드, 진행 상황 표시 |
| `download_engine.py` | 목록 조회, 다운로드, 재시도, 파일명·분리 파일 처리 |
| `download_history.py` | 사용자 계정별 SQLite 다운로드 내역 저장 |
| `history_window.py` | 다운로드 내역과 영상별 상세 결과 화면 |
| `app_runtime.py` | 내장 도구 경로, 로컬 서버 시작·종료, 취소 가능한 도구 실행 |
| `prepare_runtime.py` | 빌드용 실행 도구 다운로드 및 무결성 확인 |
| `YouTubeDownloader.spec` | 단일 EXE 패키징 설정 |
| `diagnostics.py` | 개발용 EXE 실행 검증 및 JSON 보고서 |

기존 CLI 원본은 작업 중 백업한 `.build-cache/youtube-download-original.py`에 있습니다.

## 검증 명령

EXE 자체에 포함된 GUI, Node, 로컬 서버, PO Token 플러그인, EJS, FFmpeg/FFprobe와 서버 종료를 검사합니다.
테스트 결과와 1초짜리 합성 영상은 지정한 보고서 폴더 안에 저장합니다.

```powershell
.\dist\YouTubeDownloader.exe --self-test "C:\test\report.json"
```

`--test-url`을 추가하면 해당 개별 영상을 실제로 다운로드하고 MKV 및 선택적 분리 파일을 검사합니다.
`--playlist-url`은 재생목록 조회를 검사합니다. 이 옵션들은 일반 사용에 필요하지 않습니다.

YouTube 측 변경이나 영상별 접근 제한으로 다운로드가 실패할 수 있습니다. 필요한 경우 다운로드 엔진을 갱신해 EXE를 다시 빌드해야 합니다.
내장 오픈소스 구성 요소의 출처는 `THIRD_PARTY_NOTICES.md`에 정리했습니다.
